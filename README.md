# Alguns exemplos de Redes Neurais com TensorFlow e Keras

Este repositório contém uma coleção de exemplos simples e práticos para o aprendizado de conceitos fundamentais de Inteligência Artificial e Redes Neurais Artificiais.

## Conteúdo do Repositório

O projeto aborda os seguintes tópicos de forma progressiva:
* **Perceptron:** Implementações da unidade básica de uma rede neural.
* **Redes Neurais Artificiais (ANN):** Modelos densos e multicamadas.
* **TensorFlow & Keras:** Uso das principais bibliotecas do ecossistema Google para Deep Learning.
* **Exemplos Práticos:** Treinamento, avaliação de métricas e previsões em bases de dados simples.
* **Visão Computacional:** Um exemplo simples de problema de Visão Computacional que servirá como base para o mini projeto.

## 🛠️ Pré-requisitos

Antes de executar os exemplos, você precisará ter o Python instalado em sua máquina. Recomenda-se o uso de um ambiente virtual.
